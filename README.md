## Avant mise en ligne
Choisir et autoriser le prestataire de formulaire. Le code attend une API JSON renvoyant success=true. Confirmer la boîte destinataire, activer le service, ajouter une information sur le traitement des données et tester la réception réelle. Ne jamais mettre de clé privée dans le site.
Les visuels Maison Noire et Atelier Nova sont présentés comme concepts, faute de références clients vérifiées.

## Vérifications effectuées
Rendu ordinateur inspecté dans le navigateur, sélection Signature confirmée dans le formulaire. Vérification mobile et réception e-mail à finaliser.
